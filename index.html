Tentang Saya

Fokus saya ada di persimpangan antara game design dan engineering: mengubah ide gameplay menjadi sistem yang berjalan mulus dan efisien di engine.

Saya menikmati proses membangun prototype mekanik, menulis clean game logic, dan membuat custom tools yang mempercepat workflow tim developer. Dari arsitektur State Machine karakter hingga editor scripting automation, prioritas saya adalah kode yang terstruktur, reusable, dan modular.

Saat ini aktif mengerjakan proyek-proyek personal dengan Godot dan Unity untuk memperkuat portofolio dan pemahaman engine pipeline sebelum memulai magang di semester 6.
